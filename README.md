# ApnoAI Final Project — Kayani Bakery Concept Website

This is an independent student-created concept website and is not the official Kayani Bakery website.

## Hero image
The hero image now loads from the local `bakery.jpg` file. Keep `index.html` and `bakery.jpg` together in the same folder.

## Test locally
Open `index.html` in Chrome. The hero image should appear without depending on an external image URL.

## Update GitHub and Vercel
1. Open your existing GitHub repository.
2. Upload the updated `index.html` and the new `bakery.jpg` file to the repository root.
3. Commit the changes.
4. Vercel should redeploy automatically if the repository is connected.
5. Check the live site in an incognito window and on mobile.
